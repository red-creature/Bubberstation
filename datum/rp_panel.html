/tg/ Station 13 - Modules - Types — Var Details - Proc Details

rp_panel
/datum/rp_panel

Scene Assistant - a shared writing room for nearby living mobs. Messages still go through real say/emote/subtle. This window is the scene, not a replacement for IC speech.

Vars

character_slotCharacter save slot this mob was spawned from. Never use the client's currently selected prefs slot.
draft_textUnsent composer text. Restored if the holder reconnects to this mob.
holder_is_typingTrue while this panel's holder has composer text (drives sprite + chat typing).
scene_inactiveTrue while holder is in the scene but out of range of every other member.

Procs

collect_scene_membersWalk every connected participant list so the scene is one shared group.
format_scene_textHTML-safe formatting for exported logs. Live TGUI formatting is client-side.
format_whisper_for_listenerIC whisper bands for the scene log: clear / stars / far-hear line. Returns list(message, far_hear) where far_hear is TRUE for the too-far narrative line.
holder_can_speak_icMirror living_say: dead never speaks IC; unconscious only whispers in hard crit.
is_scene_active_memberActive if alone in the scene, or within SCENE_ASSISTANT_RANGE of at least one other member.
play_scene_invite_soundAlert sound for the invitee only (not gated by scene sound toggles).
push_typing_updateLightweight partial update so typing toggles do not rebuild the whole scene payload.
remove_participantAnyone in the scene may remove anyone else. Pass voluntary = TRUE to leave yourself.
roll_scene_diceScene-log-only dice roll (no IC announce).
send_subtler_messageSubtler params skip the picker but force world.view, so we send with the intended range ourselves. subtler = 1-tile anti-ghost; subtler_antighost = same-tile anti-ghost.
set_typingContent-driven typing: on while the composer has text, off when empty. Early-outs when unchanged, and pushes a typing-only UI patch (no full refresh).
sync_scene_membershipWrite the same member set onto every panel so joins/leaves stay in sync.
